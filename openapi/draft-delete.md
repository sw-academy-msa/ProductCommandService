### 초안 삭제

`DELETE /api/v1/seller/products/{id}`는 Bearer SELLER 인증과 현재 판매자 자격 확인 후 본인 DRAFT만 삭제합니다. 요청 본문과 expectedVersion은 없으며 상품 행 잠금으로 사진 연결, 분석 결과 반영, 심사 제출과 직렬화합니다.

성공은 HTTP 200과 `{"success":true,"code":"COMMON_SUCCESS","message":"요청이 성공했습니다.","data":null}`입니다. 삭제 기록의 소유자가 같은 재요청도 200입니다. 삭제 기록도 없는 ID는 404 `PRODUCT_NOT_FOUND`, 타인 상품 또는 삭제 기록은 403 `PRODUCT_NOT_OWNER`입니다. DRAFT 이외 상태는 409 `PRODUCT_DRAFT_DELETE_NOT_ALLOWED`, 제출 또는 심사 이력이나 revisionReferenced 이미지가 있는 비정상 DRAFT는 409 `PRODUCT_DRAFT_DELETE_PROTECTED`로 원본을 보존합니다. 인증과 판매자 자격 오류는 기존 공통 계약을 따릅니다.

상품, 속성, 옵션 차원과 값, 옵션과 선택 값, FAQ, 분석 스냅샷과 미발행 분석 요청 Outbox를 같은 트랜잭션에서 삭제합니다. 최소 삭제 기록은 멱등성과 늦은 이벤트 확인을 위해 남습니다. 사진 행은 미연결 정리 대상으로 남기고 업로드 URL 만료 후 24시간 유예가 지난 다음 기존 60초 주기 잡이 임시 키와 서버 전용 결정적 키를 삭제합니다. S3 성공 후 사진 행을 지우며 실패하면 다음 주기에 재시도합니다. 따라서 삭제 성공은 S3 삭제 완료를 뜻하지 않습니다.

이미 발행된 AI 요청을 취소하는 기능은 없으며 해당 요청은 최초 시도를 포함한 최대 5회까지 실행될 수 있습니다. 삭제 후 성공과 실패 결과는 삭제 기록의 상품과 판매자가 일치하면 무시합니다. DRAFT는 공개 조회 투영 대상이 아니므로 공개 삭제 이벤트를 발행하지 않습니다. 판매자별 시간당 분석 제한은 추가하지 않습니다.

V5는 기존 행 변경 없이 삭제 기록 테이블만 만듭니다. 삭제가 발생한 뒤 이전 버전으로 되돌리면 그 버전의 정리 작업과 결과 소비자가 삭제 기록을 모르므로 이 기능의 호환 처리는 유지한 채 후속 수정 배포를 권장합니다. 애플리케이션을 되돌려도 이미 삭제한 상품은 복구되지 않습니다.
